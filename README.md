# aws-static-website

## AWS CI/CD Lab Assignments

This repository also contains:
- `Assignment-2-CodeBuild/`: Build and test automation with AWS CodeBuild
- `Assignment-3-CodeDeploy-EC2/`: EC2 deployment using AWS CodeDeploy
- `Assignment-4-Elastic-Beanstalk/`: Node.js deployment using Elastic Beanstalk
- `Assignment-5-Docker-ECR/`: Docker image build and push to Amazon ECR

Configure each AWS pipeline to use the relevant folder and its README instructions. For Assignment 3, package the folder contents with `appspec.yml` at the deployment artifact root.

**Note:** Source code is uploaded here, but AWS resources (IAM roles, buckets, build projects, EC2 instances, deployment groups, Elastic Beanstalk environments, ECR repositories, and pipelines) still need to be created and configured in AWS.
